# Starting an Assessment

There are two ways to start a new assessment:

* From the **Assessments** page — click **+ Add Assessment** in the top right
* From the **vendor profile** — go to the Assessment tab and click **Start assessment**

{% stepper %}
{% step %}
### Select a vendor

Search for the vendor you want to assess. Lema will auto-match as you type and show the vendor's category, size, and website to help confirm you've selected the right one.
{% endstep %}

{% step %}
### Select the assessment project

Choose which project(s) to run for this vendor. Each project represents an assessment scope — the set of controls that will be evaluated.

The assessment name is auto-generated from the vendor name, project, and date (e.g. _Lema AI - Default - Apr26_).

{% hint style="info" %}
Multiple projects can be selected at once if the vendor requires more than one type of assessment (e.g. Default + Privacy).
{% endhint %}
{% endstep %}

{% step %}
### Add to queue

Click **Add to queue**. The assessment is created with a status of **Ready to start** and appears in the Assessments list.

From there, open the assessment to begin reviewing controls, uploading artifacts, and working through the evaluation.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Before starting an assessment, make sure the vendor's Inherent Risk Profile is up to date. Lema uses it to determine which scopes and controls apply. An outdated IRQ can result in the wrong controls being assessed. See Inherent Risk Profile.
{% endhint %}
