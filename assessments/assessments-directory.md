# Assessments Directory

The Assessments page is your central view of every assessment — past and present. Every assessment is saved and maintained over time, giving you a complete record to support audit trails, compliance reporting, and ongoing due diligence.

Click any assessment row to open the full assessment management view.

### What's in the Table

| Column                     | What it shows                                                                            |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| **Assessment**             | Auto-generated name: vendor name, project, and start date                                |
| **Assessment Score**       | The risk rating from the most recent completed assessment                                |
| **Lifecycle**              | The vendor's current lifecycle status                                                    |
| **Project**                | The project or team this assessment belongs to (e.g. Default, 4th Party Outreach)        |
| **Assignees**              | Team members responsible for this assessment                                             |
| **Unvalidated controls**   | Controls not yet validated, broken down by severity                                      |
| **Smart evidence request** | Status of any outreach sent to the vendor requesting evidence or a response to a finding |
| **Questionnaire**          | Status of any active questionnaire sent to the vendor                                    |
| **Status**                 | Current progress state with a timestamp                                                  |

### Assessment Statuses

* **Ready to start** — assessment has been created but not yet opened
* **In progress** — assessment is actively being worked on
* **Approved** — assessment has been concluded and the vendor was approved
* **Rejected** — assessment has been concluded and the vendor was rejected

### Filtering and Search

Filter the list by **Inherent risk**, **Third-party**, **Lifecycle**, **Project**, **Assignees**, **Business owner**, or **Status**. Use the search bar to find a specific assessment, or click the download icon to export the current view.

Toggle **Group by third-party** to organize assessments by vendor — useful when a vendor has multiple assessments across different projects or time periods.
