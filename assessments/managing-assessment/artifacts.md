# Artifacts

The Artifacts tab shows all documents collected for this assessment — automatically discovered by Lema or manually uploaded by your team or the vendor. These are the files Lema uses to evaluate controls.

### Uploading Artifacts

Drag and drop files directly into the upload area, or click **Select files** to browse. Artifacts uploaded here are immediately queued for analysis — once processing is complete, Lema re-evaluates all relevant controls automatically.

### Artifact Table

| Column              | What it shows                                                       |
| ------------------- | ------------------------------------------------------------------- |
| **Artifact**        | Document type (e.g. DPA, Trust Center, Security Whitepaper)         |
| **Source**          | Where it came from: Web (auto-discovered), Manual Upload, or Vendor |
| **Link**            | Direct link to the source document                                  |
| **Analysis Status** | Whether Lema has finished analyzing the document                    |
| **Date Added**      | When the artifact was added to this assessment                      |

Filter by **Artifact type**, **Source**, or **Analysis Status** to find specific documents quickly.

### How Artifacts Drive Control Evaluation

Every artifact added to an assessment is analyzed by Lema's AI against the active control set. The more complete your artifact coverage, the more accurately controls can be validated.

{% hint style="info" %}
For time-sensitive document types — SOC 2 reports, penetration tests, and ISO certifications — Lema tracks expiration dates and validates only against current, non-expired versions. Expired artifacts are flagged automatically.
{% endhint %}

{% hint style="info" %}
Vendors can also upload artifacts directly through the Vendor Portal when a Smart Evidence Request has been shared with them.
{% endhint %}
