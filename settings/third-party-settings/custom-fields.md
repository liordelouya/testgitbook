# Custom Fields

Extend vendor and engagement profiles with fields that match your organization's workflows and data needs. Configure custom fields from **Settings → Custom Fields**.

### Field Table

The table lists all custom fields in your workspace with three columns:

* **Name** — the field label as it appears on the vendor or engagement profile
* **Type** — the field input type
* **Scope** — where the field appears

**Field types**

| Type              | Description                               |
| ----------------- | ----------------------------------------- |
| **Text**          | Free-text input                           |
| **Date**          | Date picker                               |
| **Single select** | One value from a predefined list          |
| **Multi-select**  | One or more values from a predefined list |

**Scopes**

* **Third-party** — field appears on vendor profiles
* **Engagement** — field appears on engagement records

### Adding a Custom Field

Click **+ Add custom field** and define the field name, type, and scope. The field will immediately appear on all profiles within the selected scope.

{% hint style="info" %}
Custom fields appear in the vendor profile and can be used for filtering and sorting in the third-party inventory. Use them to capture data your team tracks outside of Lema's default fields — contract dates, business categories, internal notes, and more.
{% endhint %}
