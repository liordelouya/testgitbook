# Controls

{% hint style="info" %}
Lema comes with a predefined control framework. To replace the default framework with a fully custom control library, contact your Lema customer success representative.
{% endhint %}

### Controls Table

The table lists all controls grouped by category, with each row showing the control name and the underlying assessment question. Filter by **Category**, **Weight**, **Scope**, or **Status** to navigate large control libraries quickly.

### Configuring a Control

Click any control to open its configuration panel.

**Enable / Disable**

Toggle a control on or off. Disabled control will not run during evaluations.

**Weight**

Set how much this control contributes to the Assessment Score on a scale of 1 (Low) to 5 (Critical). Higher-weight controls have a proportionally larger impact on the final score.

See [Assessment Score](../../assessments/assessment-score-residual-risk.md) for the full weighting framework and recommendations.

**Scope**

Assign the control to a scope. Each control can belong to only one scope at a time. Reassigning a control to a different scope removes it from its previous one.
