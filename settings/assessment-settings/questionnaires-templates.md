# Questionnaire Templates

Manage the questionnaire templates that can be sent to vendors during assessments from **Settings → Questionnaires**.

### Template Library

The template library lists all available templates with their name, question count, and sections. Use the search bar to find a specific template by name.

### Building a Template

Click **+ Create Template** to open the template editor.

Give the template a name and an optional description, then start adding questions. The editor auto-saves as you work.

#### Question Types

Each question can be set to one of five types using the toolbar at the top of the question editor:

| Type              | Description                                |
| ----------------- | ------------------------------------------ |
| **Single select** | One answer from a predefined list          |
| **Multi-select**  | One or more answers from a predefined list |
| **Text**          | Free-text response                         |
| **Date**          | Date picker                                |
| **File upload**   | Vendor uploads a document in response      |

#### Question Options

For select-type questions, add as many answer options as needed using **+ Add Option**. Each option has two additional controls:

* **Extra information** (speech bubble icon) — require the vendor to provide additional context if they select this answer
* **Flag** (flag icon) — mark this answer as a risk signal so it's highlighted for easy issue management when you review responses

#### Clarification Text

Add optional clarification below the question text to give vendors more context on what you're looking for.

### Using Templates in Assessments

Templates are selected when publishing a questionnaire within an assessment. A single assessment can include multiple questionnaires from different templates. See Questionnaires for how to send them to vendors.
