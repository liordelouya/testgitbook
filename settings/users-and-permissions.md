# Users & Permissions

Manage who has access to Lema and what they can do from **Settings → Users and Access**.

### User Table

The table lists all users in your organization with their name, email, and assigned role. Use the search bar to find a specific user by name or email.

### Roles

Lema has three roles. Click the role dropdown on any user row to change their role.

| Role       | Access                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| **Viewer** | Read-only access across the platform. Can export data but cannot make changes or configure settings.          |
| **Member** | Operational access across assessments, vendors, questionnaires, and findings. No access to platform settings. |
| **Admin**  | Full platform access including user management, settings, and integrations.                                   |

### Adding Users

Click **+ Add Users** in the top right to invite new team members. Users are added by email address.

### Removing Users

Hover over any user row to reveal the delete icon. Click it to remove the user from the organization. This action revokes their access immediately.

{% hint style="info" %}
Only Admins can add or remove users and change role assignments.
{% endhint %}
