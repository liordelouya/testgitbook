# Artifacts

The Artifacts tab contains all documents and evidence files associated with this vendor — whether discovered automatically by Lema, uploaded by a risk engineer, or submitted by a business user during intake.

Artifacts are the primary input for control evaluation and findings detection. Lema analyzes each artifact as it's added and keeps all previous versions for audit purposes.

### Artifact Sources

| Source            | How it gets here                                                                                                                                  |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Web**           | Automatically discovered by Lema from the vendor's public domain — trust center, privacy policy, terms and conditions, security whitepapers, etc. |
| **Manual Upload** | Uploaded directly by a risk engineer from this tab or during an assessment                                                                        |
| **Intake**        | Submitted by a business user or requester during the intake process                                                                               |

### Versioning

When a newer version of an artifact is added, Lema keeps the previous version on record. Expand any artifact row to view its version history. Lema always uses the latest version for analysis.

Where an artifact has an expiration date (e.g., a SOC 2), Lema calculates and tracks it automatically — surfacing stale artifacts before they affect your assessment.

### Uploading Artifacts

Click **+ Upload Artifacts** to add documents manually. You can also upload artifacts directly from the assessment page while working through a review — they are added to this tab and immediately available for analysis.
