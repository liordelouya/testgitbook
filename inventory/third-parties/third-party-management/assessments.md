# Assessments

The Assessments tab on the vendor profile shows all assessments — ongoing and historical — for this vendor.

### Ongoing Assessments

If no assessment is currently in progress, you'll see the option to **Start assessment**. This opens the assessment setup flow where you select the scope and kick off the review.

{% hint style="info" %}
Before starting an assessment, make sure the Inherent Risk Profile is up to date. Lema uses it to determine which controls to assess. If the IRQ is stale, you'll see a warning banner prompting you to validate it first.
{% endhint %}

### Past Assessments

The past assessments table shows every completed assessment for this vendor, including:

* **Assessment name** — auto-generated from vendor name, scope, and date
* **Assessment Score** — the final risk score at conclusion
* **Project** — the assessment scope it was run under
* **Concluded By** — the risk engineer who closed the assessment
* **Status** — the final decision: Approved, Concerning, or Unacceptable

Click any past assessment to open it and review the full findings, controls, and conclusions.

For full details on running and managing assessments, see Assessments.
